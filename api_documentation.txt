--------------------------------------------------------------------------------
1. AUTHENTICATION APIs
--------------------------------------------------------------------------------

[1.1] Login
URL: POST /api/auth/login/
Permission: Anyone
Request Body:
{
    "email": "admin@example.com",
    "password": "yourpassword"
}
Response (200 OK):
{
    "access": "eyJ0eX...",
    "refresh": "eyJ0eX...",
    "user": {
        "id": 1,
        "email": "admin@example.com",
        "first_name": "Admin",
        "last_name": "User",
        "is_admin": true,
        "client_id": null
    }
}

[1.2] Logout
URL: POST /api/auth/logout/
Permission: Authenticated
Request Body:
{
    "refresh": "eyJ0eX..."
}
Response (200 OK):
{
    "detail": "Successfully logged out."
}

[1.3] Get Profile (Me)
URL: GET /api/auth/me/
Permission: Authenticated
Response (200 OK):
{
    "id": 1,
    "email": "admin@example.com",
    "first_name": "Admin",
    "last_name": "User",
    "is_admin": true,
    "client_id": null
}

[1.4] Change Password
URL: POST /api/auth/change-password/
Permission: Authenticated
Request Body:
{
    "current_password": "oldpassword",
    "new_password": "newpassword123",
    "confirm_new_password": "newpassword123"
}
Response (200 OK):
{
    "detail": "Password updated successfully. Please log in again."
}


--------------------------------------------------------------------------------
2. CLIENT APIs
--------------------------------------------------------------------------------

[2.1] Create Client (Admin)
URL: POST /api/clients/create/
Permission: Admin Only
Request Body:
{
    "full_name": "John Doe",
    "email": "johndoe@example.com",
    "phone": "+1234567890",
    "target_destination": "Lisbon",
    "visa": "D7 Visa",
    "target_arrival_timeline": "October 2026 Arrival",
    "household_size": "2",
    "lead_advisor_name": "Sarah Guide",
    "notes": "Interested in food and culture."
}
Response (201 Created): Includes client details.

[2.2] List Clients (Admin)
URL: GET /api/clients/
Permission: Admin Only
Response (200 OK): List of client objects.

[2.3] Client Dashboard (Client Portal)
URL: GET /api/me/dashboard/
Permission: Authenticated (Client Profile Required)
Response (200 OK):
{
    "id": 1,
    "full_name": "John Doe",
    "email": "johndoe@example.com",
    "target_city": "Lisbon",
    "visa": "D7 Visa",
    "target_arrival_timeline": "October 2026 Arrival",
    "advisor": "Sarah Guide",
    "trips": []
}

3. TRIP APIs
--------------------------------------------------------------------------------

[3.1] Create Trip for Client (Admin)
URL: POST /api/clients/<client_id>/trips/
Permission: Admin Only
Request Body:
{
    "city": "Porto",
    "timeline": "Nov 12 - Nov 15, 2026",
    "guide_name": "Anna",
    "property_views": 4
}
Response (201 Created)

[3.2] List All Trips (Admin)
URL: GET /api/trips/
Permission: Admin Only
Response (200 OK): List of trips.

6. SCHEDULE / TODAY APIs
--------------------------------------------------------------------------------

[6.1] Create/Replace Day Schedule (Admin)
URL: POST /api/admin/today/<user_id>/
Permission: Admin Only
Request Body:
{
  "date": "2026-09-11",
  "items": [
    {
      "start_time": "09:00",
      "end_time": "11:00",
      "title": "Neighborhood Guide",
      "item_type": "meeting",
      "short_description": "Tour of the historical district.",
      "description": "Detailed tour description here.",
      "host_name": "Anna",
      "meeting_point": "Main Square Cafe",
      "what_to_bring": "Comfortable shoes",
      "google_maps_link": "https://maps.google.com/",
      "order": 1
    }
  ]
}
Response (201 Created)

[6.2] Update Single Schedule Item (Admin)
URL: PUT /api/admin/today/item/<item_id>/
Permission: Admin Only
Request Body: (any fields you want to update)
{
  "start_time": "09:30",
  "title": "Updated Neighborhood Guide"
}
Response (200 OK)

[6.3] Get Today's Schedule (Client Portal)
URL: GET /api/app/today/?date=2026-09-11
Permission: Authenticated Client
Response (200 OK):
{
  "client_name": "John",
  "greeting": "Good morning, John.",
  "subtitle": "Here's what's planned for today.",
  "day_number": 1,
  "date": "2026-09-11",
  "items": [...]
}

7. CITY TESTS APIs
--------------------------------------------------------------------------------

[7.1] Create City Test (Admin)
URL: POST /api/admin/city-tests/
Permission: Admin Only
Request Body:
{
  "id": "everyday-lunch",
  "category": "food",
  "title": "Everyday Lunch",
  "short_description": "Menús del día are traditional set lunches...",
  "google_maps_link": "https://maps.google.com/...",
  "external_links": [
    {
      "label": "Verified Neighborhood Favorite",
      "url": "https://..."
    }
  ],
  "note_prompts": [
    "Price...",
    "Mostly locals..."
  ],
  "question_prompts": [
    "Typical price for this neighborhood?"
  ],
  "order": 1
}
Response (201 Created)

[7.2] Get City Test Categories (Client Portal)
URL: GET /api/app/city-tests/categories/
Permission: Authenticated Client
Response (200 OK): List of categories with `saved_count` property.

[7.3] Save City Test Submission (Client Portal)
URL: POST /api/app/city-tests/<test_id>/save/
Permission: Authenticated Client
Request Body:
{
  "notes": "Price was €13. Mostly locals.",
  "question_for_liv_team": "Is tipping expected here?",
  "links": [
    "https://maps.google.com/..."
  ]
}
Response (200 OK):
{
  "success": true,
  "test_id": "everyday-lunch",
  "category_id": "food",
  "new_saved_count": 3,
  "message": "Test completed and saved"
}

[7.4] Get Solo Micro-Tests (Client Portal)
URL: GET /api/app/solo-micro-tests/
Permission: Authenticated Client
Response (200 OK): Includes title, description, and nested groups of tasks.
